# Settings / Users UI refinement — 2026-09-13

- Users list now shows only Name, Email, Default role, and Edit action.
- Removed the inline branch-access and permission checkbox wall from each user row.
- Edit User modal now has two tabs: User details and Permissions.
- User details has its own Save details action.
- Permissions contains branch access plus all direct permission checkboxes and its own Save permissions action.
- Add User is now a single upper-right action that opens the create form inline.
- Settings hierarchy groups start collapsed by default.
- Settings tree arrows use right when closed/direct and down when expanded.
- Removed the redundant non-branch Settings section hero so content has one primary heading.
- Added restrained dashboard typography normalization for more consistent heading/label sizes.
- Updated navigation and team lifecycle E2E selectors for the new interaction model.
