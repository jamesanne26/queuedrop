# QueueDrop UX fixes — 2026-09-14

Implemented from manual test feedback:

- Dashboard: Manage branches and Manage services now open the matching Settings workspace directly.
- Live Queue:
  - Get test stub no longer waits on a redirect; success/error banner and button pending state are synchronized with the server action result.
  - History opens as a modal window.
  - Terminals opens the selected branch's Terminal settings directly.
  - Branch switching shows a Please wait overlay until the new branch queue is rendered.
  - Business name removed from the Live Queue header/branch selector; branch is the primary context.
- Customer/mobile queue status:
  - Branch name appears above service name.
  - Business name removed from the details.
  - Country code and mobile number are side-by-side on mobile to reduce vertical height.
- Browser Get Queue terminal: business name removed; branch + service remain.
- TV Display:
  - Realtime updates are applied locally without forcing a server refresh after every ticket event.
  - Realtime subscription is filtered to the selected branch.
  - Disconnected fallback refresh interval reduced to 5 seconds.
  - Branch changes show a loading overlay.
- Settings > Branches:
  - Expanded branch list sorted alphabetically.
  - Active / Inactive status shown per branch.
  - Removed eager prefetch of every branch settings page to reduce initial/settings navigation load.
  - Branch switching shows a full Please wait state.
  - Branch deletion now uses a two-step custom flow: Yes/No confirmation first, then verification code.
  - Global submit loading safety timeout increased so it does not disappear before the result modal on slower saves.
- Settings > Services:
  - Remove service now uses QueueDrop custom Yes/No modal instead of browser alert/confirm.
- Settings > Roles:
  - + Create Custom Role is hidden while the create-role editor is open.
  - Role editor visual hierarchy flattened to remove stacked/nested box appearance.

Validation performed in the patch workspace:
- Changed TypeScript/TSX files were syntax-checked for balanced delimiters.
- Full `npm run typecheck` could not be completed in the sandbox because the uploaded archive did not include dependencies and the dependency install timed out; run the normal QueueDrop `npm run test:all` on the Windows project after replacing files.
